## Typography

- Display/headings: **Satoshi**, with system sans-serif fallback. The official site uses Satoshi for its principal headings. FutureMe loads the publicly available Fontshare distribution.
- Body/interface: **Inter**, with system sans-serif fallback. The official site uses Inter extensively for interface and body content.
- Hindi and Telugu: retain **Noto Sans Devanagari** and **Noto Sans Telugu** as script-appropriate fallbacks.
- Heading weights are primarily 500–700; body copy uses 400–500 with generous line height.

## Shape and spacing

- Observed official-site radii include 8px controls, 16px cards and larger media containers.
- FutureMe uses 8px controls, 12–16px cards, restrained borders and soft shadows.
- Official imagery emphasizes real student projects, robotics, technology and modern learning environments. FutureMe retains its project illustrations where useful and uses a realistic student-project photograph for the homepage.

## Identity boundary

FutureMe retains its own name and mark. NIAT supplies visual alignment only; the application must not present itself as NIAT's official website or application.
